    Welcome to tgame studio

    A tiny language for text adventures. One plain-text file per game.

    You're looking at a template. Replace it with your own story, or open an example from the Examples view in the activity rail.

    tgame language reference · format 2

    Everything the language understands.

    Directives

    @title   My Game
@author  You
@start   entrance
@set     score = 0
@list    clues
@seed    42          // deterministic randomness
@parser              // typed input instead of buttons
@typewriter          // enable typewriter effect
@typewriter fast     // or: slow, or a number (ms/char)

    Passages

    Every place in the story is a passage. Start one with :: name. Any line that isn't special is narration.

    :: entrance
The cave mouth yawns open.
Cold air spills out.

    Choices

    A line starting with * gives the player a choice. End with -> target to move; omit the target to stay in place.

    * Take the lamp -> entrance [get lamp]
* Toggle the lantern [lamp = not lamp]
* Go north -> dark_hall

    Player input

    A line starting with ? asks the player to type something. The prompt is the whole line; the answer goes in the bracketed variable at the end.

    ? What is your name? [name]

Well then, {name}.

    Pause

    A line that is just ... waits half a second before continuing. Add a duration to taste.

    The lights flicker.
...
... 800
... 2s
The lights go out.

    Typewriter

    Toggle the typewriter effect mid-passage with these marker lines:

    ~type      // enable
~normal    // disable
~fast      // enable at fast speed
~slow      // enable at slow speed

    Click anywhere in the play panel to skip the current paragraph.

    Variables

    @set score = 0

You have {score} {score == 1 | point | points}.

    Inventory

    [get lamp]            // add item
[drop lamp]           // remove item
[clear inventory]     // empty it

if has lamp:
You can see.
end

You are carrying {inventory}.

    Lists

    @list clues

[clues add footprints]
[clues remove footprints]
[clues clear]

    Conditions

    if has lamp and score > 5:
You feel confident.
end

if not has_lamp:
It is dark.
end

    Inline conditionals

    You have {score} {score == 1 | point | points}.
{if has lamp}The lamp glows.{else}It is dark.{end}

    Visits

    if visits == 1:
You arrive for the first time.
else:
You are back.
end

if visited village:
You recognize the road.
end

    Randomness

    [roll = random(1, 6)]
if roll >= 5:
You succeed!
end

    Text

    *italic* and **bold** in narration. {variable} to interpolate.

    Escaping

    A backslash before any character makes it literal, and the backslash itself is consumed.

    \->   \*   \?   \.   \~   \::   \@   \[   \]   \{   \}   \|   \\

    If the character after the backslash isn't special, the backslash is simply dropped:

    do\o\r      renders as  door
\hello      renders as  hello
\\         renders as  \

    Comments

    // anything on a line is ignored.
