    tgame language reference · format 3

    Everything the language understands.

    Directives

    Directives are global. Put them above the first passage.

    @format  3            // required; a newer number is refused by older runtimes
@title   My Game
@author  You
@start   entrance
@set     score = 0     // evaluated once, at game start
@list    clues
@seed    42            // same seed + same choices = same game
@parser                // typed commands instead of buttons
@ignore  the a an      // words the matcher skips
@typewriter fast       // or: slow, off, or ms per character

    @format 2 files still run: every line stays its own paragraph.

    Passages

    Start one with :: name, optionally followed by #tags. Names use letters (any language), digits, _ and -, are case-insensitive, and END is reserved.

    :: entrance #outdoors
The cave mouth yawns open.

    Paragraphs

    Consecutive lines join into one paragraph. A blank line starts a new one. End a line with \ for a hard line break. Leading indentation is ignored.

    For ASCII art or anything that must stay exactly as typed, fence it with triple backticks. Fenced lines are literal: no escapes, no {braces}.

    Choices

    * gives the player a choice. End with -> target to move; omit it to stay. Effects go in brackets at the end. Add once to hide the choice after it is taken. After |, list extra words the player can type.

    * Take the lamp | get lamp, grab lamp -> entrance [get lamp, once]
* Toggle the lantern [lamp = not lamp]
* Go north -> dark_hall

    Typed input

    ? What is your name? [name:text] -> next
? How old are you? [age:number]

    :text keeps the answer as text, :number re-asks until it is a number. With no type, numeric answers become numbers.

    Typed commands (@parser)

    Input is matched against choices: a number, the exact label or an alias, then any words of the label in order. If more than one choice fits, the player is asked which. help, undo, save and load always work.

    Pause and typewriter

    ...          // half a second
... 800
... 2s
~type  ~normal  ~fast  ~slow

    Click the play panel to skip a paragraph. Reduced-motion users get no typewriter.

    Variables and inline text

    @set score = 0
You have {score} {score == 1 | point | points}.
{if has lamp}The lamp glows, and you carry {count inventory}.{else}It is dark.{end}

    Inline {if} blocks may nest and contain other {braces}. Variable names are case-sensitive.

    Inventory and lists

    Items, passage names and directives are case-insensitive.

    [get lamp]   [drop lamp]   [clear inventory]
[clues add footprints]   [clues remove footprints]   [clues clear]
You are carrying {inventory}.   Clues: {clues}

    Conditions (one grammar, everywhere)

    or < and < not < comparisons < + - < * / %. So not has lamp and score > 5 means (not has lamp) and (score > 5).

    if has lamp and score > 5:
You feel confident.
else:
You hesitate.
end

has lamp     has no lamp     clues has footprints
visited village     visits == 1     count clues > 2

    When effects run

    A standalone [effect] line runs every time the passage is drawn, including after a stay-in-place choice. Prefix it to control that:

    [enter score += 1]    // only when you arrive from elsewhere
[once get coin]       // only the first time, ever

    visits counts arrivals, not redraws.

    Snippets

    >> name runs another passage in place, then carries on. A snippet may contain text, conditions and effects, but no choices or jumps.

    Randomness

    [roll = random(1, 6)]

    Seeded and deterministic (mulberry32), including in @set. Same seed and same inputs always replay the same game.

    Save, restore, undo

    Type undo, save or load, or use the buttons in the play panel. A save is the seed plus the list of choices; loading replays it.

    Escaping

    A backslash makes the next character literal. A line that starts with a backslash is always narration, so \if, \end, \// not a comment all work.

    \->   \*   \?   \.   \~   \::   \@   \[   \]   \{   \}   \|   \/   \#   \\

    Comments

    // at the start of a line is a comment. Elsewhere on a line it is ordinary text, so URLs are fine.
